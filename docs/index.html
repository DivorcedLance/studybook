Cómo estudiar con Studybook

  1. TeoríaLee el tema. Cada parte tiene un «Ver ejemplos» para practicar justo eso.
  2. EjerciciosIntenta el ejercicio antes de mirar la solución. El botón Teoría muestra la parte que se usa.
  3. Ejemplos y solucionariosPractica con ejemplos parecidos y con preguntas de PC y exámenes anteriores.
  4. InteractivoMueve los controles para ver qué cambia y practica con preguntas que se generan solas.
